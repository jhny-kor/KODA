# CISA Secure by Design 계획

KODA가 추적할 수 있는 프로젝트 예방 항목을 CISA Secure by Design 원칙에
맞춰 정리합니다.

- 고객 보안 결과를 제품 결함 관리에 포함
- 안전한 기본값·인증·세션·로깅·CORS 적용
- 취약점과 알려진 악용 취약점의 신속한 대응
- 릴리스 provenance·서명·SBOM 보관
- 보안 예외와 잔여 위험의 승인 기록
